# 교과공지 시스템 — 실제 배포용

## 포함 기능
- 학생: 전체/과목별 공지 열람, 검색 대신 과목 필터, 중요 공지, 첨부파일 다운로드
- 교과부장: 자기 과목 로그인, 공지 작성/수정/삭제, 파일 업로드
- 실시간 반영: Server-Sent Events(SSE)로 공지 변경을 접속 중인 화면에 즉시 반영
- 데이터: SQLite
- 비밀번호: bcrypt 해시 저장
- 권한: 교과부장은 자기 과목 공지만 수정/삭제 가능

## 실행
Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 데모 계정
교과부장 아이디는 과목명입니다.
- 국어 / 영어 / 수학 / 사회 / 과학 / 한국사 / 미술
- 초기 비밀번호: `1234`

실제 학교 배포 전 반드시 비밀번호를 변경하고 `SESSION_SECRET` 환경변수도 설정하세요.

## 학교 서버에 배포할 때
1. Node.js가 실행되는 서버(VPS/학교 서버/클라우드)에 폴더 업로드
2. `npm install`
3. `SESSION_SECRET`을 긴 임의 문자열로 설정
4. `npm start`
5. HTTPS와 도메인을 연결
6. 방화벽에서 웹 포트만 공개
7. `data/school.db`와 `data/uploads`를 정기 백업

## 주의
현재 교과부장 계정은 설치 시 자동 생성되는 데모 계정입니다. 실제 운영에서는 관리자 페이지를 추가해 계정을 발급/비밀번호 변경하도록 만드는 것을 권장합니다.
